一、产品概述

1.1 产品定位

「智答」（SmartAnswer）是一款面向企业级客户的知识增强型智能问答机器人。产品以检索增强生成（RAG）技术为核心架构，帮助企业将散落在文档、工单、数据库中的私有知识转化为可对话、可溯源的智能问答服务，广泛应用于智能客服、内部知识助手、IT 运维助手等场景。

1.2 核心价值主张

一、知识资产激活：支持 PDF、Word、Markdown、纯文本等多种格式的知识入库，平均 10 分钟完成一个中等规模知识库的搭建。
二、答案可信可溯源：每个回答均附带原文引用出处（文档名、章节、切片编号），点击引用可定位原文上下文，杜绝大模型的幻觉风险。
三、多源融合决策：融合向量检索、关键词检索、结构化数据查询（NL2SQL）与网络搜索四条通路，由智能体（Agent）自动编排，复杂问题自动拆解为多步任务。
四、私有化部署：支持全私有化部署，模型推理、向量索引与业务数据全部保留在客户内网，满足金融、政务等行业的合规要求。

1.3 目标客户

一、中大型企业客服中心：需要 7×24 小时自助应答，降低人工坐席成本；
二、IT 与运维团队：沉淀运维手册，缩短故障定位时间；
三、知识密集型团队：法务、咨询、研究院所等需要快速检索海量文档；
四、软件厂商：通过开放 API 将问答能力嵌入自有产品。

二、产品能力全景

2.1 知识库管理

支持创建多个独立知识库，实现知识隔离。知识库管理能力包括：

一、文档上传：单文件上限 20MB，支持 md / txt / pdf / docx 四种格式，批量上传自动排队处理；
二、智能切片：按标题层级语义切片，默认切片 500 token、重叠 50 token，切片过程保留章节路径信息；
三、状态机管理：文档入库经历 parsing → chunking → embedding → ready 四个状态，失败可一键重试，错误信息透明可查；
四、切片级溯源：支持查看任意文档的切片明细，包含切片编号、章节路径、内容与 token 数。

2.2 智能检索

一、混合检索：BM25 关键词检索与稠密向量检索并行执行，通过 RRF（倒数排序融合，K=60）合并排序；
二、相关性评估：检索结果逐条打分（1-10 分），7 分以上判定为高度相关直接引用，5-7 分为部分相关触发知识补全（CRAG），5 分以下丢弃；
三、查询改写：对话上下文自动补全指代（如「它的价格呢」自动改写为完整问题），多轮对话准确率提升 23%；
四、意图路由：智能体自动识别问题意图，闲聊类直答，知识类走检索，数据类走 NL2SQL，实时类走网络搜索。

2.3 智能体编排

系统内置六个关键决策点，全部决策过程可视化：

一、意图识别：判断问题类型与是否需要检索；
二、数据源选择：决定调用哪些检索通路（向量库 / ES / 数据库 / 网络搜索）；
三、检索评估：对召回内容进行相关性分级；
四、知识补全：检索质量不足时触发改写重查，最多重试 2 轮；
五、反思重答：生成答案自检不通过时重新组织，最多 2 轮；
六、引用组装：将命中切片装配为可点击的引用列表。

2.4 数据问答（NL2SQL）

用户以自然语言提问，系统自动生成 SQL 并在授权数据源上执行，返回数据表格与图表。执行前经过 SQL 安全校验（禁止 DROP / DELETE / UPDATE / INSERT），仅放行只读查询。回答附带生成的 SQL 语句与执行结果证据视图，全程可审计。

三、性能与规格指标

3.1 性能基准（单节点，8C32G，100 万切片规模）

一、检索延迟：混合检索 P95 ≤ 800 毫秒；
二、端到端延迟：首 token 输出 P95 ≤ 2.5 秒，完整回答平均 8-15 秒（流式输出）；
三、并发能力：单节点支持 50 路并发会话，水平扩展线性提升；
四、检索准确率：在内部评测集（1200 个问题）上 Recall@5 达到 91.4%，端到端答案准确率 87.2%。

3.2 部署规格

一、最低配置：8 核 CPU、32GB 内存、500GB SSD，可支持 10 万切片；
二、推荐配置：16 核 CPU、64GB 内存、1TB SSD，可支持 100 万切片；
三、依赖组件：MySQL 8.x（元数据）、Elasticsearch 8.x/9.x（全文与向量）、向量嵌入服务；
四、模型支持：默认接入 DeepSeek 系列（OpenAI 兼容协议），可替换为任意兼容模型；嵌入模型默认使用 text-embedding-v4（1024 维）。

四、典型应用场景

4.1 智能客服

某股份制银行信用卡中心接入后，知识库入库产品条款、常见问题 3200 篇。上线三个月，机器人独立解决率从 61% 提升至 82%，平均人工转接等待时长下降 40%，客户满意度稳定在 94% 以上。

4.2 IT 运维助手

某互联网公司运维团队将 1500 篇运维手册、历史故障工单导入知识库。值班工程师通过对话即可查询处置预案，故障平均定位时间（MTTI）从 25 分钟缩短至 9 分钟，新员工上手周期从三个月缩短至三周。

4.3 内部制度问答

某 3000 人规模制造企业将人事、财务、行政制度共 860 份文件入库，员工咨询类 HR 工单量下降 57%，制度类问题的答复一致性显著提升。

五、安全与合规

一、数据隔离：多知识库物理隔离，检索默认不跨库，跨库检索需显式授权；
二、传输加密：全链路 HTTPS，模型调用通道支持 TLS 1.3；
三、权限审计：所有问答、检索、入库操作全量留痕，支持按用户、时间、知识库维度导出审计报表；
四、内容安全：输出内容经过敏感词过滤与安全护栏，可配置禁答主题清单。
