# 数据源接入配置指南

> 文档编号：TECH-CONF-2026-004 ｜ 版本：V1.5 ｜ 更新日期：2026-05-30 ｜ 适用角色：系统管理员、实施工程师

## 一、支持的 数据源类型

系统当前支持两类外部数据源接入，用于 NL2SQL 数据问答：

| 类型 | 标识 | 典型用途 | 网络要求 |
| --- | --- | --- | --- |
| MySQL | `mysql` | 业务数据表查询（订单、销售、库存） | 后端服务可访问目标库 3306 端口 |
| HTTP API | `http_api` | 已有接口数据聚合查询 | 后端服务可访问目标 API 域名 |

接入原则：仅接入「查询型」数据；生产库建议通过只读副本或只读账号接入；单知识库最多绑定 3 个数据源。

## 二、MySQL 数据源接入

### 2.1 前置检查清单

1. 目标 MySQL 版本为 5.7 或 8.x，字符集建议 utf8mb4；
2. 创建专用只读账号，仅授予目标库的 `SELECT` 权限：

```sql
CREATE USER 'rag_reader'@'%' IDENTIFIED BY '强密码';
GRANT SELECT ON sales_db.* TO 'rag_reader'@'%';
FLUSH PRIVILEGES;
```

3. 确认后端服务器到目标库的网络连通：`mysql -h <host> -P 3306 -u rag_reader -p --default-character-set=utf8mb4`；
4. 确认待查询表已建索引，大表（超过 500 万行）建议预先建立汇总表。

### 2.2 页面配置步骤

进入「数据源管理」→「新增数据源」，填写以下字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 全局唯一，建议「业务-库-环境」格式，如 sales-mysql-prod |
| 类型 | 是 | 选择 MySQL |
| 主机 | 是 | IP 或域名 |
| 端口 | 是 | 默认 3306 |
| 数据库名 | 是 | 目标库名 |
| 用户名 | 是 | 只读账号 |
| 密码 | 是 | 保存后加密存储，页面不再回显 |
| 描述 | 否 | 数据内容说明，会注入大模型上下文帮助生成 SQL |

保存后点击「测试连通」，成功标准：连接耗时 2 秒内且无错误返回。

### 2.3 表结构同步与筛选

连通成功后系统自动抓取表结构（表名、字段、类型、注释）。配置建议：

1. 仅勾选允许查询的表，敏感表（如用户明文信息表）一律不勾选；
2. 为每张表补充中文业务描述（一句话即可），描述质量直接影响 SQL 生成准确率；
3. 枚举字段（如 status）在备注中列出取值含义，例如 `status: 1=待支付 2=已支付 3=已退款`；
4. 表结构变更后（加列、改注释）需点击「重新同步」刷新 Schema。

### 2.4 性能与安全约束

- 生成 SQL 强制只读校验，`SELECT` 之外的语句直接拒绝；
- 查询超时 10 秒，超时自动终止并提示用户缩小时间范围；
- 预估扫描行数超过 100 万行时，系统自动追加 LIMIT 或拒绝执行；
- 单次返回最多 50 行明细，聚合查询不受此限制。

## 三、HTTP API 数据源接入

### 3.1 适配要求

目标 API 须满足：

1. 支持 GET 请求，返回 JSON；
2. 响应时间 P95 不超过 3 秒；
3. 返回结构稳定，数组数据位于固定路径（如 `data.items`）。

### 3.2 配置字段

| 字段 | 说明 |
| --- | --- |
| 请求地址 | 完整 URL，支持查询参数占位符，如 `/api/v1/orders?status={status}` |
| 请求头 | 支持 Authorization 等自定义头，Token 加密存储 |
| 响应数据路径 | 数组所在 JSON 路径，如 `data.items` |
| 参数说明 | 每个占位参数的类型与取值说明，供大模型填写 |

### 3.3 示例：接入订单查询接口

请求地址：`https://crm.example.com/api/v1/orders?region={region}&month={month}`

参数说明：

- region：大区编码，取值 east / north / south / west；
- month：月份，格式 YYYY-MM。

响应数据路径：`data.items`。配置完成后在测试窗格输入示例参数验证返回结构。

## 四、数据源与知识库绑定

数据源配置完成后，需绑定到具体知识库才会生效：

1. 进入「知识库设置」→「数据源绑定」；
2. 从已测通的数据源列表中勾选（最多 3 个）；
3. 绑定后该知识库的对话中，智能体可将数据类问题路由到对应数据源；
4. 解绑立即生效，进行中的查询不受影响，新对话不再路由。

## 五、常见问题排查

### 5.1 连通测试失败

| 现象 | 可能原因 | 处理方式 |
| --- | --- | --- |
| Connection refused | 目标库未放行后端 IP | 在目标库安全组放行后端出口 IP |
| Access denied | 账号密码错误或权限不足 | 核对账号，确认 SELECT 权限已授予 |
| 连接超时 | 网络不通 / 端口错误 | 检查 VPC 路由、安全组与端口 |
| 字符乱码 | 字符集不一致 | 连接串强制 utf8mb4 |

### 5.2 查询结果不对

1. 检查表业务描述是否准确（描述误导会导致错误关联）；
2. 枚举值含义缺失时补全备注并重新同步 Schema；
3. 在「检索测试」页面直接粘贴生成的 SQL 在目标库手动执行比对；
4. 查看决策日志中 datasource 决策点，确认路由到了预期的数据源。

### 5.3 查询很慢

1. 确认过滤字段是否有索引（尤其时间字段）；
2. 缩小查询时间范围，建议按月分批查询；
3. 大表预先构建日/月粒度汇总表，将汇总表接入而非明细表。
